Siemens and Google Cloud created Knowledge Fabric, an AI system built on Spanner Graph, the Google Agent Development Kit, Gemini API, and Agent Platform, to modernize legacy codebases. It uses knowledge graphs and specialized agents to break refactoring of hundreds of millions of lines of legacy code into smaller, agent-led tasks.
